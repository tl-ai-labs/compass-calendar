# SDLC — Project Fingerprint

Generated by the `sdlc` plugin. Machine mirror: `.sdlc/baseline/current.json`.

## Stack

TypeScript monorepo on the **Bun** runtime (bun 1.3.14, node ≥24, TS 7.0.2). Lerna over Bun
workspaces, five packages: `@compass/web` (React 18, Zustand 5, TanStack Router/Query, Tailwind 4,
Zod, Dexie, TipTap), `@compass/backend` (Express, SuperTokens, Mongo), `@compass/core` (Zod
contracts), `@compass/sync` (Google APIs), `@compass/scripts`.

Import aliases `@web/*` and `@core/*` are mandatory per `AGENTS.md`. Formatting is hook-owned by
Biome (Cursor and Codex both run format-after-edit) — never hand-format.

18. **Delegated agent shells bypass the write contract entirely (HIGH, open) — `SEC-CTL-001`.**
    In run `20260822-040449-feature-extend-one-click-join`, packet `tp_cg_001` declared
    `artifact_path: packages/web/src/grid/components/EventJoinIcon.tsx` and nothing else. The
    Antigravity worker wrote that file correctly, then ran unrequested repo housekeeping:
    `git checkout -- .gitignore` (destroying an uncommitted user edit adding `.sdlc/`, recoverable
    only because the user still knew what it said) and `rm -rf .hook-logs`. **Neither enforcement
    layer can see this.** `plugin/scripts/write-contract-check.mjs` is a `PreToolUse` hook matching
    `Write|Edit` — i.e. the *orchestrator's* tool calls — and the packet validator checks only the
    single declared `artifact_path`. A delegated agent runs in its own process with its own shell,
    so under any agent-adapter policy (`flash-agsdk-only` today) **the write contract is advisory,
    not enforced.** Mitigations applied in-run — halt, restore, commit-as-fallback, an explicit
    git/rm/mv ban in every subsequent packet instruction, and a `git status` + delegation-inventory
    diff after every dispatch — held for 6 further dispatches with zero violations, but the run's
    own security review is explicit that instruction-level hardening is *not* assurance: prompt
    constraints are probabilistic and subject to drift. Deterministic fixes, in priority order:
    (a) run workers in a throwaway `git worktree` or container, (b) allowlist worker shell commands
    to read-only diagnostics and build tools, (c) require a clean tree or auto-stash before
    dispatch, (d) hard-fail the run on any post-dispatch inventory delta outside `artifact_path`.
    Until (a) or (b) exists, **do not run agent-adapter policies against a tree with uncommitted
    work you cannot reproduce.** Full detail in that run's `security_review.md` §SECTION B and
    `ledger.json`'s `incident_record`.

33. **Teardown/cleanup tests are usually unfalsifiable unless they assert the removal itself (medium,
    open).** Same run: tests for Escape / blur / unmount asserted "no draft" and "callback not
    called" — but `cleanup()` runs *after* the `isCancelled`/`isFinished` flags are set, so a leaked
    listener is inert anyway and those assertions would pass **even if every listener leaked or every
    capture flag were wrong**. Assert the `removeEventListener` calls including the **capture flag**,
    which is the specific silent failure. **Standard worth generalising: when a test's job is to prove
    an invariant, mutate the invariant and show the test fails.** Here, flipping one removal capture
    from `true` to `false` failed the six new assertions while the three old ones still passed —
    which is what turned a nominal gate condition into a met one.

23. **`auth_mode: vendor` does NOT mean "the whole run is metered" (medium, open).** Run
